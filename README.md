# Product Admin Dashboard

A responsive product administration dashboard built with Next.js, React, JavaScript, Tailwind CSS and Axios using the DummyJSON API.

## Tech Stack

- Next.js
- React
- JavaScript / JSX
- Tailwind CSS
- Axios
- DummyJSON API

## Features

- User login
- Logout
- Protected product pages
- Product listing
- Responsive desktop table
- Responsive mobile cards
- Pagination
- Page size selection
- Search
- Debounced search
- Category filtering
- Product sorting
- Product details
- Product reviews
- Add product
- Edit product
- Delete product
- Form validation
- Loading states
- Empty states
- Error states
- Retry functionality
- URL query parameters
- Axios request cancellation
- Protection against stale search results
